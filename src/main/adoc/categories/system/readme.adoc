== Hardware

link:https://www.hardkernel.com/shop/odroid-m1s-with-8gbyte-ram/[Odroid M1S]

.Specification Hardware
* CPU RK3566: ARM Cortex-A55 with 4 cores
* 8G RAM
* 64G eMMC
* on-board M.2 NVMe slot

.Specification Power
* 0.8-3.5 Watt

== OS setup

.Image Download
* link:https://armbian.com/fr/boards/odroidm1s[Armbian]

.Flash
* Use *Armbian Imager*, select board, and Debian Trixie image, Flash on SD-card

.Install on eMMC and customize
* On Board:
** insert SD-card
** connect keyboard,screen,network,power
* Boot shows on screen
* Set root password when asked
* Create user and set password when asked

[source,bash]
----
$ armbian-config

# Select System and enter menus to flash on internal disk eMMC (64G)

# Reboot

# Run again the config tool, and change keyboard layout, local, etc
----

.Docker install
[source,bash]
----
# Dependencies
$ apt update
$ apt install ca-certificates curl

# Install steps from https://docs.docker.com/engine/install/debian/ 
$ install -m 0755 -d /etc/apt/keyrings
$ curl -fsSL https://download.docker.com/linux/debian/gpg -o /etc/apt/keyrings/docker.asc
$ chmod a+r /etc/apt/keyrings/docker.asc

# Add the repository to Apt sources:
$ tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/debian
Suites: $(. /etc/os-release && echo "$VERSION_CODENAME")
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF

$ apt update
$ apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# Post-install
$ usermod -aG docker odroid

# Tuning
$ vi /etc/docker/daemon.json
{
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "10m",
    "max-file": "3"
  }
}
$ service docker restart

# reboot here
...
$ docker run hello-world
----
